## Variants

- **Primary** — The main action on a screen or section (Save, Pay, Continue)
- **Secondary** — Alternative action next to Primary (Cancel)
- **Tertiary** — Quiet supporting actions (Learn more)

```jsx
import { Button } from '../components/Button/Button';

<Button variant="Primary" size="Medium" label="Pay now" onClick={handlePay} />
<Button variant="Secondary" size="Medium" label="Cancel" />
<Button variant="Tertiary" size="Medium" label="Learn more" />
```
